## Что может 4IFIR 2.7
* **Новая оболочка Latitude UI:** полная замена qLaunch с эффектом матового стекла (настройка размытия и плотности подложек в `Настройки → Темы`).
* **Анимированные фоны для игр:** индивидуальное видеосопровождение для каждой игры на домашнем экране.
* **Кастомизация иконок:** замена обложек на собственные логотипы или автоматическая загрузка из базы SteamGridDB.
* **Автоматическое обновление:** нативное обновление 4IFIR и HOS напрямую из меню `Настройки → Система`.
* **Фоновый MTP-сервер:** прямое подключение к ПК по USB для обмена файлами и установки игр без необходимости открывать сторонние приложения.
* **Встроенные сервисы по нажатию `R`:**
  * `R + Gameshare` → Встроенный Homebrew Store.
  * `R + Nintendo eShop` → Встроенный Ownfoil (фоновая установка игр со своего сервера).
  * `R + Виртуальные игровые карты` → Встроенный файловый менеджер.
* **Ultrahand Overlay:** оверлей нового поколения с удобной навигацией и поддержкой пакетов.
* **4IFIR Wizard:** интерактивный конфигуратор тонкой настройки вольтажей, частот и таймингов ([qret/Ultrahand-4IFIR-Wizard](https://github.com/qret/Ultrahand-4IFIR-Wizard)).
* **Разгон железа:** до 3009 МГц CPU, до 1612 МГц GPU и до 3000 МГц RAM (индивидуальный потолок для каждого экземпляра).
* **Автоматический андервольтинг/овервольтинг** и адаптивные алгоритмы eBamatic.
* **Автоподстройка частоты дисплея (аналог VRR)** и Auto Frame Rate для внешних экранов в док-станции.
* **DC Dimming** для Nintendo Switch OLED.
* **Автоматическая активация 60 FPS** без ручной установки патчей в поддерживаемых играх.
* **Настройка таймингов RAM в реальном времени** через EMC Magician.
* **Overlay со счетчиком FPS и системными метриками** (Status Monitor PRO).
* **Фоновый FTP-сервер** и модули расширения (подключение геймпадов sys-con, захват экрана SysDVR).
