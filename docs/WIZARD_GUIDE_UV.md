## Советы перед настройкой
* Используйте **EmuNAND**.
* Сделайте бэкап сохранений.
* Установите тестовые игры для проверки стабильности (RDR, No Man's Sky, Hogwarts Legacy).
* Текущие параметры хранятся в файле `atmosphere/kips/loader.kip`.
* Если после изменения какого-то из параметров консоль зависает при старте:
  * Используйте **`Service → Restore Factory Defaults`** или **`Service → Backup manager`**.
  * Загрузитесь в **Stock (semi-stock)** через Hekate и верните значения в 4IFIR Wizard.
  * Либо используйте **KipTool** (`Hekate → Payloads → kiptool.bin → KIP Wizard`).
  * Файлы бэкапов находятся в: `/atmosphere/kips/.bak/mariko/` (для Mariko) и `/atmosphere/kips/.bak/erista/` (для Erista).
* Запускайте HB Menu с зажатой кнопкой **R** на игре для полного доступа к ОЗУ.
* Для проверки стабильности используйте MicroMemBench и требовательные игры в течение 15–20 минут.

## CPU
> Все тесты в данном разделе проводите с активным профилем памяти **EMC: 4IFIR Optimized S**.  
> Во время тестов **CPU Freq Governor** должен быть выключен:  
> `Ultrahand → 4IFIR → Edit app Profile → CPU Freq Governor → Off`.

Рекомендуется начинать настройку с процессора, так как CPU не зависит от видеоядра и памяти.

***

**Переходим в Advanced → CPU:**

* **Min Voltage (CPUv)** — нижний порог рабочего напряжения процессора.  
  *(Чем ниже напряжение, тем меньше нагрев и расход заряда)*  
  1. Выставляем значение на шаг ниже безопасного базового (например, 600 мВ).  
  2. Перезагружаем систему через **Reboot the console**.  
  3. Проводим 5–10 минутный тест в игре на минимальной частоте CPU:  
     `Ultrahand → 4IFIR → Temporary overrides → CPU`.  
  4. Если система работает стабильно, опускаем вольтаж на шаг ниже до выявления предела кремния.  
  5. Фиксируем последнее стабильное значение.
* **Low MHz Undervolt** — уровень андервольта для частот CPU <= 15хх МГц:  
  1. Повышаем **Level** на один шаг.  
  2. Перезагружаемся и тестируем в играх на частотах ниже 1500 МГц.  
  3. Если сбоев нет, повышаем уровень дальше до достижения границы стабильности.
* **High MHz Undervolt** — андервольт для частот процессора выше 15хх МГц:  
  1. Повышаем на один шаг.  
  2. Перезагружаемся и тестируем в CPU-зависимых сценах на максимальной частоте (`4IFIR Maximized`).
* **Max Voltage (CPU Maximum Voltage)** — верхний предел напряжения CPU:  
  Рекомендуется оставить **eBamatic** либо понижать по одному шагу с тщательной проверкой стабильности.
* **dCPUv** — корректировка напряжений в диапазоне средних частот 12хх–18хх МГц:  
  Рекомендуется оставить **eBamatic**. Действуйте с осторожностью; предварительно сделайте резервную копию в `Service → Backup manager`.
* **Speed Shift** — энергосбережение вспомогательных узлов SoC:  
  Повышайте уровень энергосбережения по одному шагу и проверяйте общую отзывчивость системы.

## GPU
> Все тесты проводите с включенным профилем памяти **EMC: 4IFIR Optimized S**.  
> Во время тестов **GPU Freq Governor** должен быть отключен:  
> `Ultrahand → 4IFIR → Edit app Profile → GPU Freq Governor → Off`.

**Подготовка к настройке GPU:**
1. Запустите GPU-интенсивную игру (RDR, Hogwarts Legacy, No Man's Sky).  
2. Зафиксируйте частоту GPU: `Ultrahand → 4IFIR → Temporary overrides → GPU → 460 MHz`.  
3. Откройте `Ultrahand → 4IFIR → Miscellaneous` и зафиксируйте текущий вольтаж **GPU volt**.  
4. Пошагово увеличивайте частоту GPU, проверяя вольтаж в Miscellaneous, пока напряжение не начнет расти. Это и есть максимальная частота при минимальном напряжении.

***

**Переходим в Advanced → GPU:**

* **Min Voltage (GPUv)** — нижний порог напряжения видеоядра:  
  1. Повышаем Stage (понижаем напряжение) на один шаг и перезагружаемся.  
  2. Запускаем игру на найденной минимальной базовой частоте.  
  3. Проверяем стабильность в течение 10 минут. При сбоях или артефактах возвращаем вольтаж на шаг назад.
* **Undervolt Mode (GPU Eco Mode)** — уровень андервольта по всей сетке частот видеочипа:  
  Тестирование проводится аналогично, но на высоких частотах GPU (от 768 МГц и выше).

***

### Дополнительные корректировки GPUv

Тонкие смещения vMin доступны прямо в меню **`Advanced → GPU`** (а также в `Advanced → Micro-Enhance Logic`):

* **vMin Offset (`pMeh 19`)** — смещение автоматического нижнего порога напряжения GPU для режима памяти **EMC: 4IFIR Optimized** (шаг 5 мВ).  
* **vMin Offset (max RAM) (`pMeh 21`)** — смещение порога напряжения GPU для режима памяти **EMC: 4IFIR Optimized S** на максимальной частоте памяти (шаг 5 мВ).

Следить за текущим реальным вольтажом GPU удобно через оверлей **InfoNX** или **Status Monitor PRO**.

### Ручная настройка таблицы GPU Voltage Table

В визарде доступна поканальная ручная калибровка вольтажей для каждого частотного шага GPU:
1. Перейдите в **`Advanced → GPU → GPU Voltage Table`**.
2. Выберите конкретную частоту видеоядра.
3. Отрегулируйте значение в мВ.
4. Перезагрузитесь через **Reboot the console** и проверьте стабильность в игре с зафиксированной частотой GPU.
