## Советы перед настройкой
* Используйте **EmuNAND**.
* Сделайте бэкап сохранений.
* Установите игры для проверки стабильности настроек (RDR, Zelda TOTK, No Man's Sky).
* Текущие параметры, установленные в **4IFIR WIZARD**, хранятся в файле `atmosphere/kips/loader.kip`.
* Если после изменения какого-то из параметров перестала включаться консоль:
  * В меню визарда есть **`Service → Restore Factory Defaults`** и **`Service → Backup manager`** (применяются удержанием **`(A)`**).
  * Если система не стартует нормально — удерживайте `(VOL-)` при включении, выберите в Hekate режим **Stock (semi-stock)**, откройте Ultrahand (`L + R + ▲`) → меню пакетов (`►`) → **4IFIR Wizard** и верните настройку.
  * Если не получилось зайти в semi-stock, используйте **KipTool** (`Hekate → Payloads → kiptool.bin → KIP Wizard`) для правки `loader.kip` прямо из загрузчика.
  * Бэкапы профилей сохраняются по ревизиям: `/atmosphere/kips/.bak/mariko/` (для Mariko) и `/atmosphere/kips/.bak/erista/` (для Erista). Стандартный `loader.kip` всегда можно взять из архива дистрибутива 4IFIR.
* Установите HB Menu как приложение (NSP), чтобы иметь полный доступ к ресурсам памяти консоли.
* Для первоначального теста стабильности запускайте **MicroMemBench**.
* Для создания максимальной нагрузки можно перевести консоль в режим док-станции с помощью **ReverseNX-RT** в Ultrahand. Для каждого теста достаточно 15–20 минут активной игры.

## 4IFIR WIZARD

### CPU
> Все пункты в данном разделе тестируйте с включенным профилем памяти **EMC: 4IFIR Optimized S**. 

Настройки CPU не зависят от памяти и видеоядра, поэтому их можно настроить один раз.  
Если какой-то из параметров будет «перекручен», консоль может зависнуть на этапе загрузки. В этом случае загружаемся в Semi-Stock или KipTool и откатываем значение на шаг назад.  
В разделе CPU ключевыми для настройки являются два параметра: **Min Voltage** и **Low MHz Undervolt**. Параметры со значением *eBamatic* оптимально сбалансированы по умолчанию.

***

**Переходим в Advanced → CPU:**

* **Min Voltage (CPUv)** — выбор нижнего порога потребления процессора.  
  > Чем ниже напряжение, тем меньше потребление. Выставляем его на шаг ниже (например, было 620, стало 590 мВ). Перезагружаем систему (**Reboot the console**) и проводим тесты.  
  > Тесты проводим в играх, выставляя минимальную частоту через:  
  > `Ultrahand → 4IFIR → Temporary overrides → CPU` *(действует до перезагрузки)*.  
  > Если все стабильно, опускаем напряжение еще на шаг ниже до достижения предела кремния. Фиксируем стабильное значение.
* **Low MHz Undervolt** — уровень андервольта для частот процессора <= 15хх МГц.  
  > Чем выше значение, тем ниже потребление на частотах до 15хх МГц. Выставляем на шаг выше, тестируем в играх на частотах до 15хх МГц с выключенным Governor:  
  > `Ultrahand → 4IFIR → Edit app Profile → CPU Freq Governor → Off`.  
  > Повышаем значение до тех пор, пока система сохраняет стабильность.
* **Max Voltage (CPU Maximum Voltage)** — выбор верхнего порога потребления процессора.  
  > **Рекомендуется оставить значение eBamatic**. При желании тонкой настройки понижайте по 1 шагу и тестируйте в CPU-зависимых играх (RDR, Hogwarts Legacy) в режиме 4IFIR Maximized.
* **dCPUv** — корректировка напряжений в диапазоне средних частот 12хх–18хх МГц.  
  > Рекомендуется оставить **eBamatic**. Действуйте с осторожностью; перед изменением создайте бэкап в `Service → Backup manager`.
* **Boost Clock (CPU Boost Clock)** — частота буста на экранах загрузки игр (по умолчанию eBamatic).
* **High MHz Undervolt** — андервольт для высоких частот процессора (> 15хх МГц). Рекомендуется оставить **eBamatic** либо поднимать по 1 уровню с проверкой в тяжелых сценах.
* **Speed Shift** — энергосбережение вспомогательных узлов SoC. Рекомендуется **eBamatic** или постепенный подъем с проверкой стабильности.

### GPU
> Все пункты в данном разделе тестируйте с активным профилем памяти **EMC: 4IFIR Optimized S**.

На вольтажи видеоядра влияют два ключевых параметра: **Min Voltage (GPUv)** и **Undervolt Mode (GPU Eco Mode)**.  
Ошибки настроек GPU проявляются в виде артефактов текстур, светящихся точек или оранжевого экрана.

***

**Переходим в Advanced → GPU:**

* **Min Voltage (GPUv)** — нижний порог напряжения видеоядра.  
  > 1. Повышаем Stage (понижаем вольтаж) на один шаг и перезагружаемся.  
  > 2. Запускаем требовательную игру (RDR, No Man's Sky, Hogwarts Legacy).  
  > 3. Отключаем GPU Governor: `Ultrahand → 4IFIR → Edit app Profile → GPU Freq Governor → Off`.  
  > 4. Задаем тестовую частоту: `Ultrahand → 4IFIR → Temporary overrides → GPU → 460 MHz`.  
  > 5. Контролируем напряжение GPU через оверлей `InfoNX` или `Status Monitor`.  
  > 6. Проверяем стабильность в течение 10 минут. Если все гладко — оптимизируем дальше.
* **Undervolt Mode (GPU Eco Mode)** — выбор уровня андервольта на всей сетке частот видеочипа.  
  > Чем агрессивнее уровень, тем меньше энергопотребление на частотах выше базовых. Тестирование проводите на частотах GPU от 768 МГц и выше.
* **vMin Offset (`pMeh 19`) и vMin Offset (max RAM) (`pMeh 21`)** — тонкая доводка нижнего порога GPU шагом 5 мВ:  
  * `vMin Offset` — для режима памяти Optimized E.  
  * `vMin Offset (max RAM)` — для режима памяти Optimized S на максимальной частоте.

***

### RAM
Сценарии использования:
1. **Эко-режим (Optimized E):** для энергоэффективной игры в 30–60 FPS на частотах до 1600–2000 МГц.
2. **Сбалансированный режим:** 2100–2400 МГц для стабильных 60 FPS в портативе.
3. **Максимальная производительность (Optimized S):** 2400–3000 МГц (для тяжелых игр и док-станции).

***

**Переходим в Advanced → RAM:**

* **Frequency** — выбор частоты памяти, доступной в профиле `4IFIR Nextgen → 4IFIR Optimized S`.  
  > Выбираем частоту, перезагружаемся через `Reboot the console`, затем активируем:  
  > `Ultrahand → 4IFIR → Temporary overrides → Memory → 4IFIR Optimized S`.  
  > Тестируем в **MicroMemBench** и тяжелых играх (Zelda TOTK, RDR) в течение 15 минут.
* **EMC Balance (eBal)** — набор оптимизаций энергоэффективности и пропускной способности памяти:  
  * `0 (eBamatic)` — автоматический умный подбор.  
  * `1` — максимальная производительность (требует повышенного напряжения).  
  * `2` — оптимальный режим для большинства чипов памяти на частотах выше 2000 МГц.  
  * `3` — базовый стабильный режим.  
  * `4` — для экстремально высоких частот в доке.
* **Vddq** — напряжение питания чипов памяти (понижайте по шагу с проверкой стабильности).
* **Vdd2** — верхний предел напряжения контроллера памяти.
* **EBA-Shift** — поправка режима eBal (значение 2 позволяет повысить 8-й тайминг).
* **EMC DVB Mode** — адаптивный механизм контроллера RAM (по умолчанию eBamatic).
* **Core Timings** — грубая ручная настройка восьми основных таймингов в KIP.  
  > Для быстрой и безопасной настройки таймингов на лету без перезагрузок используйте оверлей [**EMC Magician**](EMC_MAGICIAN.md).

***

### Дополнительные оптимизации

* **eBAMATIC Stage** (в главном меню визарда) — уровень адаптивной оптимизации памяти. Поочередно повышайте значение на шаг и проверяйте стабильность в MemBench и играх.
* **4ekate** — аппаратный разгон шины памяти в Hekate (прирост около 200 МБ/с). В 4IFIR 2.7 включен по умолчанию. Если консоль испытывает трудности с выходом из режима сна — снизьте профиль 4ekate до ST1.

### Профиль EMC: 4IFIR Optimized (ECO режим)

Настройки режима **Optimized E** доступны в меню **`Advanced → RAM → Optimized Mode (1600 MHz)`**:
* **Efficiency Stages (`sMeh 8`)** — стэйджи эффективности ступени E. Значение **`2`** дает ощутимый прирост скорости на ступени E. (Если на экране в доке возникают полосы — верните `0`).
* **vMin Offset (`pMeh 19`)** — тонкая подстройка минимального вольтажа GPU для ступени E.
* **VDDQ-VDD2 Voltage (`pMeh 20`)** — вольтажи VDDQ/VDD2 для ступени E.
* **Optimized Target (`sMeh 16`)** — целевая базовая частота ступени E (1600 МГц или 1331 МГц).
