## Советы перед настройкой
* Используйте **EmuNAND**.
* Сделайте бэкап сохранений.
* Установите тестовые игры (RDR, Zelda TOTK).
* Текущие параметры, установленные в **4IFIR WIZARD**, хранятся в файле `atmosphere/kips/loader.kip`.
* Если после изменения какого-то из параметров перестала включаться консоль:
  * Используйте встроенный аварийный сброс **`Service → Restore Factory Defaults`** или восстановление из **`Service → Backup manager`**.
  * Загрузитесь в **Stock (semi-stock)** через Hekate и верните значения в 4IFIR Wizard.
  * Либо используйте **KipTool** (`Hekate → Payloads → kiptool.bin → KIP Wizard`).
  * Файлы резервных копий хранятся по путям: `/atmosphere/kips/.bak/mariko/` (для Mariko) и `/atmosphere/kips/.bak/erista/` (для Erista). Чистый `loader.kip` всегда доступен в архиве прошивки.
* Запускайте HB Menu в режиме приложения (с зажатой кнопкой **R** на любой игре).
* Для первоначальной проверки стабильности запускайте **MicroMemBench**.
* Для тестирования под экстремальной нагрузкой можно использовать бенчмарк **Ultracam для Zelda TOTK** или Red Dead Redemption в режиме док-станции через **ReverseNX-RT**. Для каждого теста достаточно 15–20 минут активной игры.

### RAM

Сценарии использования:
1. **Эко-режим (Optimized E):** для 30–60 FPS с минимальным нагревом и расходом батареи (частоты 1600–2000 МГц).
2. **Сбалансированный режим:** 2100–2400 МГц — оптимально для портативного режима большинства игр.
3. **Максимальная производительность (Optimized S):** 2400–3000 МГц (для тяжелых проектов и игры в док-станции).

***

**Переходим в Advanced → RAM:**

* **Frequency** — целевая частота оперативной памяти, доступная в профиле `4IFIR Nextgen → 4IFIR Optimized S`.  
> 1. Выбираем желаемую частоту памяти и перезагружаемся через `Reboot the console`.  
> 2. После загрузки активируем разгон памяти:  
> `Ultrahand → 4IFIR → Temporary overrides → Memory → 4IFIR Optimized S`.  
> 3. В шапке оверлея в графе `MEM: xxxx MHz` проверяем частоту.  
> 4. Тестируем в **MicroMemBench** и играх (10–15 минут). Если консоль зависает — снижаем частоту на ступень назад.
* **EMC Balance (eBal)** — баланс между производительностью и энергопотреблением:  
  * `0 (eBamatic)` — автоматический умный выбор.  
  * `1` — максимальная скорость шины (требует более высоких вольтажей).  
  * `2` — энергоэффективный режим (стабилен на большинстве консолей на частотах выше 2000 МГц).  
  * `3` — дефолтный профиль.  
  * `4` — высокочастотный профиль для док-станции.
* **Vddq** — напряжение питания чипов памяти:  
  > Понижайте по одному шагу и проверяйте стабильность в играх. Слишком низкое значение может привести к сбою файловой системы.
* **Vdd2** — верхняя граница напряжения контроллера памяти:  
  > Настраивайте после калибровки таймингов, так как тайминги чувствительны к Vdd2.
* **EBA-Shift** — поправка режима eBal (значение 2 позволяет увеличить 8-й тайминг).
* **EMC DVB Mode** — адаптивный механизм контроллера RAM (рекомендуется оставить eBamatic).
* **Core Timings (1–8)** — ручная фиксация базовых таймингов в KIP.  
  > Для настройки и мониторинга таймингов в реальном времени рекомендуется использовать инструмент [**EMC Magician**](EMC_MAGICIAN.md).

***

### Дополнительные оптимизации

* **eBAMATIC Stage** (в главном меню визарда) — уровень агрессивности оптимизаций eBamatic. Повышайте на шаг и проверяйте стабильность в тестах.
* **4ekate** — оптимизация контроллера в Hekate (~200 МБ/с). В 4IFIR 2.7 включена в дистрибутив по умолчанию.

### Профиль EMC: 4IFIR Optimized (ECO режим)

Настройки энергоэффективного профиля собраны в подменю **`Advanced → RAM → Optimized Mode (1600 MHz)`**:
* **Efficiency Stages (`sMeh 8`)** — стэйджи эффективности на ступени E. Значение **`2`** обеспечивает существенный прирост скорости. (При появлении мерцающих полос в доке верните `0`).
* **vMin Offset (`pMeh 19`)** — точная подгонка нижнего порога напряжения GPU под ступень E.
* **VDDQ-VDD2 Voltage (`pMeh 20`)** — уровень питающих напряжений VDDQ/VDD2 для ступени E.
* **Optimized Target (`sMeh 16`)** — базовая опорная частота ступени E (1600 МГц либо 1331 МГц).
