## Советы перед настройкой
* Используйте **EmuNAND**.
* Сделайте бэкап сохранений.
* Установите тестовые игры для проверки стабильности (RDR, Zelda: Tears of the Kingdom, No Man's Sky).
* Текущие параметры, настроенные в **4IFIR WIZARD**, хранятся в системном файле `atmosphere/kips/loader.kip`.
* Если после изменения какого-либо параметра консоль не запускается:
  * В меню визарда всегда доступен откат: **`Service → Restore Factory Defaults`** или применение сохранённой копии через **`Service → Backup manager`**.
  * Загрузитесь в **Stock (semi-stock)** через Hekate и верните предыдущие настройки в Wizard.
  * Либо используйте **KipTool** (`Hekate → Payloads → kiptool.bin → KIP Wizard`), позволяющий редактировать параметры `loader.kip` напрямую из загрузчика.
  * Резервные копии профилей лежат по путям: `/atmosphere/kips/.bak/mariko/` (для Mariko) и `/atmosphere/kips/.bak/erista/` (для Erista).
* Для первоначального теста стабильности памяти запускайте **MicroMemBench**.
* Для создания максимальной нагрузки можно перевести консоль в режим док-станции с помощью **ReverseNX-RT** в Ultrahand. Для каждого теста достаточно 10–15 минут активного геймплея.

## Настройка через 4IFIR WIZARD

Откройте оверлей **Ultrahand** комбинацией **`(L) + (R) + (▲)`**, нажмите **`(►)`** для перехода к разделу пакетов и выберите **4IFIR Wizard**.

### CPU
> Все тесты в данном разделе проводите с активным профилем памяти **EMC: 4IFIR Optimized S**.  
> Если параметр будет «перекручен», консоль зависнет на этапе загрузки. В этом случае загружаемся в Semi-Stock или KipTool и откатываем значение на шаг назад.

**Переходим в Advanced → CPU:**

* **Min Voltage (CPUv)** — выбор нижнего порога потребления процессора.  
  *(Чем ниже напряжение / выше Stage, тем ниже энергопотребление)*  
  1. По умолчанию установлено значение **ECO ST1** (или безопасный заводской уровень).  
  2. Поднимите его на один шаг (**ST 2** или снизьте вольтаж на один шаг).  
  3. Перезагрузите систему через **Reboot the console** внизу меню и проведите тест.  
  > Тесты проводите в играх, выставляя минимальную частоту процессора через:  
  > **Ultrahand → 4IFIR → Temporary overrides → CPU** *(настройки действуют до перезагрузки)*.  
  4. Если система работает стабильно, оптимизируйте значение дальше.  
  5. Зафиксируйте последнее стабильное значение.

* **Low MHz Undervolt** — уровень андервольта для частот процессора <= 15хх МГц.  
  *(Чем выше Level, тем агрессивнее снижено потребление на низких частотах)*  
  1. По умолчанию установлено значение **0**.  
  2. Повысьте значение на один шаг (**Level 1**).  
  3. Перезагрузите систему и протестируйте в игре на частотах ниже 1500 МГц (отключив CPU Governor в Edit app Profile).  
  4. Если зависаний нет, повышайте уровень дальше до выявления предела стабильности.

### GPU
> Все тесты проводите с включенным профилем памяти **EMC: 4IFIR Optimized S**.

**Переходим в Advanced → GPU:**

* **Min Voltage (GPUv)** — минимальный порог напряжения видеоядра.  
  *(Чем выше Stage / ниже напряжение, тем экономичнее консоль)*  
  1. По умолчанию установлено заводское значение.  
  2. Повысьте значение на один шаг и перезагрузитесь.  
  3. Запустите требовательную игру (RDR, Hogwarts Legacy, Zelda TOTK).  
  4. Отключите GPU Governor: **Ultrahand → 4IFIR → Edit app Profile → GPU Freq Governor → Off**.  
  5. Зафиксируйте частоту GPU: **Ultrahand → 4IFIR → Temporary overrides → GPU → 691 MHz**.  
  6. Проверьте стабильность в течение 10 минут. При сбоях или артефактах снизьте значение на шаг назад.

* **Undervolt Mode (GPU Eco Mode)** — уровень андервольта по всей сетке частот видеочипа.  
  > Настройка аналогична предыдущему пункту, но тестирование рекомендуется проводить на высоких частотах GPU (выше 768 МГц).

### Дополнительные оптимизации

* **eBAMATIC Stage** (находится прямо в главном меню Wizard) — уровень агрессивности оптимизаций eBamatic:  
  Поочередно повышайте значение на шаг и проверяйте стабильность в MicroMemBench и играх.
* **4ekate:**  
  Активация режима ST2 в Hekate дает прирост пропускной способности памяти порядка 200 МБ/с. В 4IFIR 2.7 оптимизации 4ekate включены в сборку по умолчанию. Если на вашей консоли возникают проблемы с выходом из спящего режима, переключите режим в 4ekate на ST1.
