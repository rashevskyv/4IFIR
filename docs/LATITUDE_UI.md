# Latitude UI — Новая графическая оболочка 4IFIR

**Latitude UI** — это современная графическая оболочка нового поколения, полностью заменяющая стандартный домашний экран Nintendo Switch (**qLaunch**). Начиная с версии **4IFIR 2.7**, Latitude обеспечивает глубокую кастомизацию интерфейса, интеграцию фоновых сервисов и удобные быстрые действия прямо с главного экрана.

---

## 1. Внешний вид и персонализация

### Эффект матового стекла (Frosted Glass)
В Latitude реализован эффект прозрачности и матового стекла, преображающий системный интерфейс.

* **Где настраивать:** `Системные настройки` → `Темы`
* **Доступные параметры:**
  * **Размытие (Blur):** регулировка интенсивности эффекта размытия заднего плана.
  * **Плотность подложек (Opacity / Density):** настройка прозрачности плашек меню, плиток игр и информационных панелей.

---

## 2. Кастомизация игр на домашнем экране

### Анимированные (видео) фоны
Теперь для каждой игры можно установить персональный живой фон, который воспроизводится при наведении на плитку игры на главном экране.
* Поддерживаются динамические заставки и видеоряды.
* Настройка осуществляется индивидуально для каждого тайтла через контекстное меню игры.

### Смена иконок игр (SteamGridDB и свои логотипы)
Больше не нужно мириться со стандартными или некрасивыми иконками:
* **Интеграция со SteamGridDB:** автоматический поиск и загрузка официальных или фанатских постеров, вертикальных/квадратных обложек и логотипов прямо из базы SteamGridDB по сети.
* **Пользовательские логотипы:** возможность загрузить собственное изображение с карты памяти и применить его к любой установленной игре.

---

## 3. Обновленные системные компоненты

* **Новое HB Menu:** переработанное меню Homebrew с современным дизайном, быстрой навигацией и полной интеграцией в стилистику Latitude.
* **Новый Альбом:** обновленное системное приложение галереи скриншотов и видеозаписей с улучшенной производительностью и просмотром медиафайлов.

---

## 4. Быстрые действия (Шорткаты через кнопку `R`)

На домашнем экране Latitude стандартные системные плитки получили быстрые альтернативные действия при запуске с зажатой кнопкой **`R`**:

| Сочетание | Запускаемый сервис | Описание |
| :--- | :--- | :--- |
| **`R` + Gameshare** *(Общий доступ к играм)* | **Встроенный Homebrew Store** | Собственный магазин приложений и оверлеев. Позволяет скачивать, обновлять и устанавливать Homebrew без необходимости использовать устаревший HB Appstore. |
| **`R` + Nintendo eShop** | **Встроенный Ownfoil** | Продвинутый клиент для установки игр с собственного сервера. Поддерживает **фоновую загрузку и установку**, не блокируя использование консоли. |
| **`R` + Виртуальные игровые карты** | **Встроенный файловый менеджер** | Полнофункциональный проводник по SD-карте: управление файлами, перенос, удаление, просмотр структуры папок прямо из интерфейса. |

> [!TIP]
> Чтобы запустить встроенный сервис, зажмите и удерживайте кнопку **`R`** на правом контроллере, после чего нажмите **`(A)`** на соответствующей системной иконке.

## 5. Фоновый MTP-сервер

В 4IFIR 2.7 встроен постоянно работающий **MTP-сервер**:
* **Как подключить:** просто соедините Nintendo Switch с компьютером с помощью USB-кабеля (режим передачи данных).
* **Что доступно:**
  * Прямой доступ к содержимому MicroSD карты в проводнике Windows / macOS / Linux.
  * Установка игр: перетащите `.nsp`, `.nsz`, `.xci` файлы в соответствующую виртуальную папку установки без необходимости предварительно открывать DBI или заходить в Hekate USB Tools.
* Сервер работает в фоне и не требует ручного запуска или настройки.

---

## 6. Автоматическое обновление системы и 4IFIR

Обновление программного обеспечения консоли теперь бесшовное:
* **Где находится:** `Системные настройки` → `Система`
* При наличии подключения к интернету консоль автоматически проверяет и предлагает установить:
  * Свежие версии компонентов сборки **4IFIR**.
  * Актуальные обновления системного ПО **Horizon OS (HOS)**.
* Больше нет необходимости вручную скачивать архивы через сторонние апдейтеры (AiO Switch Updater) или вручную распаковывать прошивку через Daybreak.
