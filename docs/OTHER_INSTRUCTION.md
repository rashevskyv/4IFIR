# Инструкция по обновлению 4IFIR и системного ПО (HOS)

> [!IMPORTANT]
> Данная инструкция предполагает, что вы используете **EmuNAND**!  
> В **4IFIR 2.7** процедура обновления максимально автоматизирована и интегрирована напрямую в системные настройки консоли.

---

## 1. Автоматическое обновление 4IFIR и HOS (Основной метод)

Начиная с версии **4IFIR 2.7**, вам больше не нужно скачивать прошивку вручную через сторонние загрузчики или вручную устанавливать файлы через Daybreak:

1. Подключите консоль к сети Wi-Fi.
2. На главном экране **Latitude UI** откройте **Системные настройки**.
3. Перейдите в раздел **Система** → **Обновление**.
4. Система в фоновом режиме проверит наличие обновлений:
   * Сборки компонентов **4IFIR**.
   * Совместимой версии системного ПО **Horizon OS (HOS)**.
5. Нажмите **Обновить** и подтвердите действие.
6. Консоль самостоятельно загрузит нужные компоненты, подготовит окружение и перезагрузится в уже обновленную систему.

---

## 2. Оффлайн-обновление прошивки HOS через Daybreak (Резервный метод)

Если на консоли отсутствует подключение к интернету или требуется установить конкретную фиксированную версию HOS:

1. Скачайте архив нужной прошивки HOS на компьютер.
2. Подключите Switch к ПК кабелем USB (благодаря **фоновому MTP** консоль мгновенно отобразится в Проводнике) либо вставьте SD-карту в картридер.
3. Распакуйте папку с файлами прошивки в директорию `firmware/` в корне SD-карты.
4. Откройте **HB Menu** (нажмите `(A)` на плитке альбома или игры).
5. Запустите приложение **Daybreak** → нажмите **Install**.
6. Перейдите в папку `firmware`, дождитесь окончания верификации файлов и нажмите **Continue**.
7. На вопрос **Select settings mode** выберите **Preserve settings** (сохранение настроек).
8. На вопрос **Select driver variant** выберите **Install (FAT32 + exFAT)**.
9. По завершении нажмите **Reboot** для перезагрузки.

---

## 3. Обновление официальной прошивки (OFW / SysNAND)

Для обновления официальной системы (OFW / Semi-Stock):
1. Перезагрузите консоль в **Hekate** → выберите **Reboot → OFW**.
2. В официальной прошивке перейдите: `Системные настройки → Система → Обновление системы` и обновитесь штатными серверами Nintendo.

---

## 4. Восстановление при сбое загрузки (Черный экран после логотипа)

Если вы случайно обновили версию HOS до того, как обновили 4IFIR, или произошел сбой:

### Способ 1: Восстановление KIP через KipTool
1. Зажмите `(VOL-)` при включении консоли для входа в **Hekate**.
2. Перейдите в **Payloads** → запустите `kiptool.bin`.
3. В меню **KIP Wizard** проверьте параметры процессора (например, `SpeedShift` установите в **25** или **100**).
4. Нажмите **Apply changes** и перезагрузите консоль.

### Способ 2: Чистое обновление файлов 4IFIR через USB / Hekate
1. Загрузитесь в **Hekate** удерживая `(VOL-)`.
2. Подключите консоль к ПК по кабелю USB:
   * Перейдите в **Tools → USB Tools → SD Card**.
   * На ПК откроется накопитель SD-карты.
3. Удалите с карты всё, **КРОМЕ** папок:
   * `emuMMC`
   * `Nintendo`
   * (и папок с резервными копиями сохранений, например `JKSV`).
4. Скопируйте свежий архив [4IFIR.zip](https://github.com/rashevskyv/4ifir-checker/releases/latest/download/4IFIR.zip) на SD-карту с заменой.
5. Выполните безопасное извлечение на ПК, нажмите **Close** на экране Switch и перезагрузитесь: **Home → Reboot → Normal**.
